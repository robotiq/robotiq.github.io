repositories of the tools they document (e.g. `tactile_sensors`,
`2f85_cpp`, `robotiq_ros`); each tool's own repository is the authoritative
source for its license.

## Firmware and other non-website content

Some linked source repositories contain files under licenses other than
this site's own — for example, `tactile_sensors`' `firmware/bootloader_host.py`
is licensed GPL-3.0-or-later. This documentation site does not bundle or
redistribute that file; it only links to it as source-code documentation.
Anyone redistributing that file, or a product that bundles it, should
consult `tactile_sensors`' own repository and license directly — that
obligation is out of scope for this site.

## Keeping this page current

The [third-party notices](/docs/third-party-notices) list regenerates on
every build, so it never drifts from `package.json`. The rest of
this page (the logo inventory and the firmware note above) is reviewed
manually whenever a submodule or a dependency changes in a way that
affects it, and at least once a year regardless.
