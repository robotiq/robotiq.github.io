## Introduction

Lots of software tools are available to work with `Robotiq` products. Some of
those tools are developped and maintained by `Robotiq` and some other by the
community of developpers.

You will find in this documentation website the documentation for the software
tools developped and maintained by `Robotiq` as well as reference to the
software tools developped by the community.

:::info
For details about `Robotiq` product hardware, please refer to the corresponding
Hardware manual available on [Robotiq support website](https://robotiq.com/support).
:::
