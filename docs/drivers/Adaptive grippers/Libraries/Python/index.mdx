[pyRobotiqGripper](https://github.com/castetsb/pyRobotiqGripper) is an
open-source Python library designed to simplify the control of Robotiq
grippers. It allows developers to operate and communicate
with the hardware using the Modbus RTU protocol, either over a traditional
serial port or an Ethernet connection.
