## Introduction

Python is the premier language for rapid prototyping because it minimizes
development time and lets you focus on logic rather than boilerplate code. Its
clean, readable syntax mimics natural language, allowing developers to write
and test ideas with fewer lines of code than languages like C++ or Java.
Supported by a massive ecosystem of pre-built libraries for everything from
data science to robotics, Python enables teams to quickly assemble functional
proofs-of-concept, pivot instantly based on testing, and validate core
software behaviors before committing to costly, production-grade infrastructure.

## Support

[pyRobotiqGripper](https://github.com/castetsb/pyRobotiqGripper) is an
open-source Python library designed to simplify the control of Robotiq
grippers. It allows developers to operate and communicate
with the hardware using the Modbus RTU protocol, either over a traditional
serial port or an Ethernet connection.
