## Introduction

[MuJoCo](https://mujoco.org/), which stands for Multi-Joint dynamics with
Contact, is a high-performance physics engine designed specifically for
robotics, biomechanics, machine learning, and reinforcement learning.

## Support

The model of the 2F85 gripper is provided by google team:
